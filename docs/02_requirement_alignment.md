## 防止偏题的执行约束

1. 不预测 PM2.5、AQI 或次日污染，不训练回归或分类模型。
2. 不将季节、气象、年份或预定义污染等级输入主聚类，再声称“发现”了这些标签。
3. 不以 accuracy、F1、RMSE 或 R² 作为核心结果。
4. 不只交一张 PCA 散点图。必须有真实聚类、参数比较、原始浓度画像与簇差异讨论。
5. 不把 DBSCAN 退化、簇重叠或敏感性差异隐藏掉。

数据仓库页面给数据标注的常见任务类别，不限定研究只能做该类别。本项目主动从连续污染物特征中发现结构，符合 Topic 3；不能因为来源页面显示 Regression 就转回预测任务。

## 课程硬要求与项目建议的区分

硬要求是公开科学数据、来源/规模/特征/局限、无监督聚类、至少两种方法或参数及簇差异讨论。六种污染物、18 小时阈值、k=2…8、三种算法、稳定性实验、建议报告页数和排期，均是本项目为执行清晰与分析可信而制定的规则，可以在有理由、留有版本记录的前提下调整。

未知项包括最终截止时间、提交格式、评分细则和组员配置。未据此虚构限制，也不需要等待这些信息才能按现有方案实施核心研究。
