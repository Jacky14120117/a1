# 交付清单、排期与验收

本轮只完成规划和可执行交接准备：课程阅读提炼、项目方案、符合性检查、完整细节方案、架构、目录、AGENTS.md、项目技能、官方数据来源核验。聚类实验和最终提交材料尚待实施。

## 最终提交建议

- `README.md`：研究问题、Topic 3、环境与运行方式、结果路径及主要限制。
- 数据来源、许可证、下载恢复方式和哈希；若提交 raw，保留原文件。若不提交 raw，保证能重新取得同一版本。
- 实际安装得到的 `requirements-lock.txt`、代码与 `configs/project.yaml`。
- 三本从头可运行的 Notebook，或教师接受的等价研究脚本加说明。
- 一个完整主运行目录，包含全候选、标签、选参规则、稳定性、敏感性与来源清单。
- 最终报告，建议英文正文 10–14 页或等价内容，格式以教师要求为准。
- 答辩材料，建议 12 页主线，可用附录展示参数与完整审计。

不提交 `.venv`、缓存、大量重复运行或无关下载。选择进入最终报告的图表保留原始运行引用。课件不是本项目生成的研究成果。

## 最终验收清单

- [ ] 标题、摘要、方法和结论均明确是无监督知识发现。
- [ ] 来源、作者、原始规模、实际分析规模、字段、单位和局限完整。
- [ ] raw 未修改，原始 ZIP 和 CSV 哈希可追溯。
- [ ] 六列与日期集合一致，主矩阵没有背景或标签字段。
- [ ] K-Means 与 Ward 均有多参数真实比较，不预设最终 k。
- [ ] DBSCAN 退化与噪声口径真实披露。
- [ ] 主方法在同空间、同日期上评价；不同分母与敏感性空间明确标注。
- [ ] 至少两项实际簇差异有数量、原始浓度或列联证据。
- [ ] 有种子稳定性、时间块扰动和一种变换敏感性。
- [ ] PCA 有方差解释率，且只用作展示。
- [ ] 簇名来自观测，未宣称因果、污染源或健康等级。
- [ ] 报告数字与最终运行一致，所有图表和外部主张有来源。
- [ ] 测试通过，干净环境复现完成，交接文档更新为真实状态。
