## 固定清洗与聚合规则

1. 将 `NA`/空值/非有限值识别为缺失。负污染物浓度转为无效并记录。零浓度保留。
2. 构造本地时间 `datetime(year,month,day,hour)`；按 Asia/Shanghai 的本地日期聚合，不先转 UTC 后跨日分组。原文件没有时区偏移列，这是项目的时间解释约定。
3. 验证站点唯一、小时键唯一和完整网格。完全相同的重复记录可在派生副本中去重并留日志；同一小时冲突值不自动平均，先核查来源。
4. 每个污染物在一天内分别计数有效小时。六列全部 >=18 才保留该日，每列日值是它实际有效小时的算术平均，不要求六列的有效小时完全重合。
5. 没有插值、零填补、按标签删点或主分析缩尾。真实高浓度日保留，异常只标记审查。
6. 全日不合格时，该日保留在 coverage 表并记录各列计数；不进入主矩阵。缺失日不会补造为连续观测。
7. 聚类矩阵按日期升序，六列顺序固定。`date` 单独保存，不作为数值特征。

18 小时阈值为预先设定的研究质量规则，相当于每日 75% 的记录覆盖要求。它不是本方案验证过的空气质量法规门槛，也不将日均浓度换算为官方 AQI。

## 派生表契约

| 文件 | 每行代表什么 | 必备列 |
| --- | --- | --- |
| `data/interim/hourly_clean.csv` | 原小时记录的清洗副本 | timestamp、station、六污染物、气象、原 No |
| `data/processed/daily_coverage.csv` | 所有 1,461 日 | date、各列 n_valid、eligible、exclusion_reason |
| `data/processed/daily_pollutants.csv` | 合格日，预计 1,333 行 | date、六列日均浓度 |
| `data/processed/daily_context.csv` | 所有日的背景 | date、year、month、season、各气象统计及有效计数 |
| `data/processed/features_main.csv` | 与主日表同序 | date、六列 log+z 数值；实际拟合时显式去 date |

气象变量逐列独立聚合：TEMP、PRES、DEWP、WSPM 在 >=18 有效小时下取均值，否则记 NA；RAIN 仅当 24 小时齐全时取和，否则记 NA。风向可选使用众数并记录并列规则，主报告可不使用风向。背景缺失不会删除污染物合格日。

季节约定为春 3–5 月、夏 6–8 月、秋 9–11 月、冬 12–2 月，是后解释分组规则。季节统计同时给出合格日/日历日覆盖率，不能只比较不同长度时期的绝对数量。
