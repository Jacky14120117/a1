# 后续实现需要的有效测试

当前尚未创建模型测试。实现对应功能时再加入测试，避免测试不存在的假接口。

| 场景 | 应验证的行为 |
| --- | --- |
| 一列仅 17 小时有效、其他列 24 小时 | 该日不进入主矩阵 |
| 所有六列恰好 18 小时有效 | 该日合格；日均按各自有效小时求值 |
| NA、零、负浓度 | NA/负值无效；零保留，不统一补零 |
| 日期乱序或背景字段丰富 | 主 X 按日排序，且只包含固定六列 |
| 气象缺失与主日表连接 | 不减少合格日，不让气象进入 X |
| 同一小时冲突数据 | 报错或显式核查，不静默平均 |
| DBSCAN 全噪声/一个簇加噪声 | 不把 -1 当第二簇，内部指标 null 且有原因 |
| 簇编号置换 | ARI=1，而非按数字直接相等 |
| 日历块抽样 | 同方法共享日集合，无重复日，时间块按完整日历定义 |
| 同数据/配置/种子重跑 | 日期、特征、设置一致；标签等价、指标在容差内一致 |

用小型构造数据验证规则边界，用真实来源预核验作数据集成检查。无需为 Markdown 文案或每个简单包装函数编写重复实现的测试。
